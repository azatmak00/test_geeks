# Pokemon Card App

Это простое приложение на React, которое отображает карточки покемонов, используя данные из [PokeAPI](https://pokeapi.co/).

## Описание

Приложение загружает список покемонов через API и отображает их в виде карточек. Каждая карточка включает имя покемона и изображение.

## Технологии

- React
- JavaScript
- PokeAPI (https://pokeapi.co/)
